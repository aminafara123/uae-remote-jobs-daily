UAE Remote Jobs Daily

A curated daily feed of remote and Dubai-workable tech jobs, scanned from 10 public sources every morning, deduplicated and filtered.

How it works

  1. Each morning a scheduled task on my PC pulls job postings from 10 public job boards, APIs and feeds.
  2. It keeps roles in IT operations, GRC and compliance, cloud, and AI automation. It drops roles that are blocked for the UAE, tags each location as eligible, verify or unknown, and checks each one against everything it has seen before, so new postings are listed separately.
  3. It publishes the day's report to GitHub and updates the RSS feed.
